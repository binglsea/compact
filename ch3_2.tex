{\definition{} 
	\textup{(Smith [1975]\textsuperscript{\cite{Smith1975}})} 
An open cover $\mathscr{U}$ of [X] is a weak $\overline{\theta}$-cover if $\mathscr{U}$ has an open refinement $\mathscr{G} = \bigcup_{n \in \omega} \mathscr{G}_n$ where each $\mathscr{G}_n = \{G_{n, \alpha} : \alpha \in \Gamma_n\}$ such that:

\textup{(i)}
For each $x \in X]$, there exists $m \in \omega$ such that $0 < \vert{}\{G \in \mathscr{G}_m : x \in G\}\vert{} < \omega$).

\textup{(ii)}
$\mathscr{G}^* = \{\bigcup \mathscr{G}_n : n \in \omega\}$ is a point-finite open cover of [X].
}

The family $\mathscr{G}$ is called a weak $\overline{\theta}$-refinement of $\mathscr{U}$. [X] is weakly $\overline{\theta}$-refinable if every open cover is a weak $\overline{\theta}$-cover.
