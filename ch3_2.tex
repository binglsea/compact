{\definition{} 
	\textup{(Smith [1975])} 
An open cover $\mathcal{U}$ of [X] is a weak $\overline{\theta}$-cover if $\mathcal{U}$ has an open refinement $\mathcal{G} = \bigcup_{n \in \omega} \mathcal{G}_n$ where each $\mathcal{G}_n = \{G_{n, \alpha} : \alpha \in \Gamma_n\}$ such that:

\textup{(i)}
For each $x \in X]$, there exists $m \in \omega$ such that $0 < \vert{}\{G \in \mathcal{G}_m : x \in G\}\vert{} < \omega$).

\textup{(ii)}
$\mathcal{G}^* = \{\bigcup \mathcal{G}_n : n \in \omega\}$ is a point-finite open cover of [X].
}

The family $\mathcal{G}$ is called a weak $\overline{\theta}$-refinement of $\mathcal{U}$. [X] is weakly $\overline{\theta}$-refinable if every open cover is a weak $\overline{\theta}$-cover.
