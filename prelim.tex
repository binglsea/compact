\chapter{Preliminaries}  

\section{Basic	Covering	Properties}  
We use the  usual terms and notations. 
An ordinal is the set of all smaller ordinals, 
and a cardinal is an Initial ordinal. 
We use $\kappa, \mu$ for cardinals; $\lambda$
a for infinite cardinal;  $\alpha, \beta, \gamma, \delta$ denote ordinal numbers. $\omega = \{0, 1, 2, \dots\}$ is the smallest infinite cardinal. 
$|A|$ denotes the cardinality of a set $A$.
The empty set $\phi$ is the unique set $B$ such that $|B| = 0$.
